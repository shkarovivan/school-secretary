# School Secretary — умный школьный секретарь

Агент-система для семьи: отвечает на вопросы по электронному дневнику
(edu.gounn.ru, Нижегородская область) и школьным чатам в MAX, следит за
событиями и присылает дайджесты, помогает с домашними заданиями
(учебники, решения). Разворачивается на Raspberry Pi рядом с MyTasksBackend.

## Статус

Этап 0 — разведка (см. [docs/plan.md](docs/plan.md)).

## Контур системы

- **Коннекторы**: дневник (мультипрофильные сессии, автообновление),
  MAX-чаты (мост), учебники (RAG).
- **Хранилище**: SQLite — оценки, ДЗ, расписание, сообщения чатов.
- **Агентное ядро**: Python + Agent SDK, инструменты над хранилищем,
  скоупинг доступа по профилям.
- **Интерфейсы**: бот в MAX (основной, iOS из коробки), API для MyTasks.

## Приватность

Секретарь читает только данные собственных учётных записей семьи
(свои дети, свои чаты). Учетные данные и сессии — только в локальных
конфигах (.env, профили), в репозиторий не попадают.
